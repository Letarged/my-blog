## Foothold

<Callout type="note">
Always check HTTP response headers early — version banners are often revealing.
</Callout>

The login form at `/login` is vulnerable to UNION-based SQLi.

<Finding severity="high" title="SQLi in login endpoint" cvss={8.1}
         vector="CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N" cwe="CWE-89">
The `username` parameter is passed directly into a SQL query without
parameterisation. An attacker can extract the full `users` table via
`UNION SELECT`.
</Finding>

<Spoiler label="Payload hint">
```sql
' UNION SELECT 1,username,password FROM users-- -
```
</Spoiler>

## Privilege Escalation

<Callout type="opsec">
