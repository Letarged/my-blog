About

I am a certified penetration tester based in Slovakia, holding the HTB Certified Penetration Testing Specialist (CPTS) and HTB Certified Web Exploitation Specialist (CWES) credentials. My work centres on offensive security across three domains: network infrastructure assessments, web application testing, and Active Directory attack path analysis, with a growing focus on integrating AI tooling into the enumeration and reporting workflow.

I work with clients and practice environments internationally. My methodology starts with exhaustive enumeration before any exploitation attempt. Every assumption gets documented; every finding is paired with a tested remediation path and delivered in a structured, reproducible report.
